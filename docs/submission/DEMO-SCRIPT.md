# 90-second demo script

Goal: a reviewer sees, in the first 20 seconds, something only Arc makes possible. Record on a phone-sized window. No voice-over needed; use on-screen captions.

| Time | Screen | Caption / line |
|---|---|---|
| 0:00 | Home, "Arc pulse" cards | "Other feeds say [reported $]. The pools really hold [real $] of USDC." |
| 0:12 | Tap a flagged token from "Caught today" | "This one shows $2.5k of liquidity. It holds $1.8 of USDC." |
| 0:22 | Token page: score, five sub-scores, flags | "1–10 score. Every flag has an on-chain reason you can check." |
| 0:35 | Tap an explorer link | "It's read straight from Arc mainnet." |
| 0:42 | Exit check: tap Sell $1K | "Selling $1k would return at most $X. That's the real exit." |
| 0:52 | Open an unscored token | "No score yet, and it says why. Riven doesn't guess." |
| 1:02 | Screener sorted by "Liquidity gap" | "Biggest gap between reported and real liquidity, first." |
| 1:12 | `/accuracy` | "Riven publishes its own hit rate, even when the sample is small." |
| 1:20 | Paste `/api/arc/badge/0x…` into a page, or show the JSON | "Launchpads and wallets can embed the score." |
| 1:28 | Home hero | "Riven. Every token on Arc, rug-checked." |

Before recording: pick one flagged token and one unscored token that exist on the live site, and note their addresses. Turn the mascot sound off.
